# Roadmap

## MVP
- [x] Estrutura do repositório
- [ ] Gravação por push-to-talk (barra de espaço) funcionando ponta a ponta
- [ ] Transcrição via API
- [ ] Geração de código pelo LLM
- [ ] Deploy e execução via SSH no Raspberry Pi
- [ ] Demonstração: "pisca 3 vezes a 3 Hz ao apertar o botão"

## Melhorias

- [ ] Histórico das instruções e códigos gerados
- [ ] Validação do código com `ast` em vez de lista de padrões
- [ ] Comando de voz para parar o programa atual
- [ ] Suporte a mais componentes (buzzer, sensores)
