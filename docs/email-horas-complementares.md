**Sobre o projeto — "Speach2Pi"**

Trata-se do desenvolvimento de um sistema que permite controlar um Raspberry Pi por meio de comandos de voz em linguagem natural. O fluxo funciona da seguinte forma:

1. O usuário pressiona a barra de espaço no computador e fala a instrução desejada (por exemplo: *"quando eu apertar o botão, quero que o LED pisque 3 vezes a 3 Hz"*);
2. Ao soltar a tecla, o áudio gravado é enviado a uma API de transcrição (*speech-to-text*);
3. O texto resultante é inserido em um prompt enviado a um modelo de linguagem (OpenAI ou Anthropic), que gera o código correspondente;
4. O código é transferido para o Raspberry Pi, que passa a executá-lo imediatamente, controlando o hardware conectado (um botão e um LED).

O projeto envolve integração de hardware (GPIO do Raspberry Pi), captura e processamento de áudio, consumo de APIs de IA, comunicação entre computador e dispositivo embarcado, e tratamento de segurança na execução do código gerado.
